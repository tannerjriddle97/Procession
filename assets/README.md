# Original game content

`procession/` contains runtime definitions, cuboid meshes, seven original pixel textures, recipes, localization and a documentary progression catalog. Regenerate with `tools/content/Generate-Content.ps1`; preview with `tools/content/Preview-Content.ps1`.

The opening bell references installed vanilla assets by namespace. No game texture/mesh is copied into the package. Concept images remain separate. See [VISUALS.md](../docs/VISUALS.md).
